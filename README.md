# PuzzleCam — لعبة ألغاز بالتحكم بحركات اليد

## فكرة المشروع
تطبيق تفاعلي يعمل داخل المتصفح، يستخدم كاميرا الجهاز لتتبع حركات اليدين. يلتقط صورة ويحوّلها إلى لغز مكوّن من 9 قطع، ثم يتيح ترتيب القطع باستخدام الإيماءات بدلًا من الفأرة
.

## طريقة العمل
1. يُظهر المستخدم يديه أمام الكاميرا ويقرّب الإبهام والسبابة في كل يد لتحديد إطار الصورة.
2. بعد العد التنازلي، تُلتقط الصورة وتتحول إلى لغز 3×3 بتأثير أبيض وأسود.
3. يحرّك المستخدم القطع بضم الإبهام والسبابة فوق القطعة وسحبها إلى مكانها.
4. عند إكمال اللغز تظهر العبارة: **نجحت فرقد عدنان farkadadnan**.
5. يمكن حفظ النتيجة بإغلاق قبضة اليد، ثم تنزيل شريط الصور بعد إكمال ثلاث صور.

## التقنيات المستخدمة
- **HTML وCSS:** بناء الواجهة وتنسيقها.
- **JavaScript وCanvas 2D:** منطق اللعبة والرسم ومعالجة الصورة.
- **MediaPipe Tasks Vision 0.10.14:** اكتشاف اليدين وتتبع نقاطهما.
- **Python HTTP Server:** تقديم ملفات التطبيق محليًا فقط؛ معالجة الكاميرا واللعبة تجري داخل المتصفح.

## متطلبات التشغيل
- جهاز مزوّد بكاميرا.
- متصفح Chrome أو Edge، مع السماح بالوصول إلى الكاميرا.
- Python لتشغيل الخادم المحلي.
- ملفات MediaPipe والنموذج الموجودة في مجلدي `vendor` و`models` في النسخة المعدّلة.

## خطوات التشغيل
افتح نافذة Terminal داخل مجلد المشروع، ثم نفّذ:

```bash
python -m http.server 5500 --bind 127.0.0.1
```

افتح المتصفح على:

[http://localhost:5500](http://localhost:5500)

اسمح باستخدام الكاميرا واترك نافذة الخادم مفتوحة. لإيقافه اضغط **Ctrl+C**.

يوجد أيضًا ملف `run.bat` مُعدّ للجهاز الحالي. عند استخدامه على جهاز آخر، يجب تعديل مسار Python فيه أو استخدام الأمر السابق.

> يجب تشغيل التطبيق عبر الخادم المحلي، وليس بفتح `index.html` مباشرة. بعد تعديل الملفات استخدم **Ctrl+F5** لتحديث الصفحة.
